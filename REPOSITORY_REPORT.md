## How to Access

### Web App
git clone https://github.com/Clinton18rotich/construction-manager.git
cd construction-manager
python3 -m http.server 8080
termux-open-url http://localhost:8080/

### Android App
git clone https://github.com/Clinton18rotich/ConstructionManager.git
cd ConstructionManager
./gradlew assembleDebug
